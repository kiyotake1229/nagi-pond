# 池の写真を撮って共有する

- 管理番号: #0003
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-08
- 関連: #0001、#0005（iOS 版の共有シート）

## 概要

右上のカメラのボタンで、今の池を一枚の写真（1080×1350、縦 4:5）にして、SNS などへ共有できるようにした。節気・日付・鯉の数が入る。口コミで知ってもらうきっかけを作るための機能。

## 対象ファイル

- `index.html`

## 変更内容

- 上の帯の音ボタンの下にカメラのボタン（`#shotBtn`）
- `takePhoto`: 池の canvas の今の絵を縦長に切り抜いて敷き、上下を暗くして、右上に節気（縦書き）と読み、左下に「凪の池」・「寒露のころ　2026年10月8日」・「鯉 7匹　満開 13回　図鑑 9/12」を書き、細い枠を付ける。画面の部品（ボタン類）は写らない
- 撮るときに白い光（`#shutter`）、短い紙の音、触覚
- 写真の確認画面（`#photo`）に「閉じる」「共有する」。画像は長押しで保存もできる
- `sharePhoto`: iOS アプリ版は `Filesystem` に書いてから `Share`（共有シート）。ブラウザは Web Share API（ファイル付き）。どちらも使えないときは「画像を長押しして保存してください」と知らせる
- Esc キーと背景のタップで閉じる
