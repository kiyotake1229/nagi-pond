# 設定の「池のしつらえ」で、鍵の印が文字の上に出る

- 管理番号: #0021
- 種類: FIX（軽微な修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-10
- 関連: #0001

## 概要

設定の「池のしつらえ」で、まだ解放していない項目（例: 浮き灯籠「満開12回で」）の鍵の印が、文字の横ではなく上に縦に並んでいた。

## 対象ファイル

- `index.html`（CSS）

## 変更内容

- 原因: 設定の行の中の `span` を縦並びにする指定（`.row>span`）が、鍵の印の `.lock` より強く効いていた
- `.row .lock` として横並び（`flex-direction: row`）を指定した
