# 省電力（触らないあいだは描く回数を減らす）

- 管理番号: #0020
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-10
- 関連: #0015（おやすみ中は描かない）

## 概要

池は毎秒60回描き続けていた。寝る前に置いたまま使う、という使い方では電池の減りが気になる。しばらく触らないと描く回数を自動で減らす「省電力」を足した。初期はオン、設定の「電池」で切れる。

## 対象ファイル

- `index.html`（`frame` / `frameGap`、設定の「電池」）
- `support.html`（よくある質問「電池の減りが気になる」）

## 変更内容

- 最後に触った時刻（`lastInput`）を、画面のどこを押しても・キーを押しても・水面をなぞっても新しくする
- 触らずに30秒たつと毎秒30回、5分たつと毎秒20回に減らす（画面の書き換え（毎秒60回）の2回に1回、3回に1回だけ描く）。触るとすぐ毎秒60回に戻る
- 呼吸の最中・満開の演出の最中は、なめらかさを優先して減らさない
- 保存データの設定に `eco`（初期 true）を追加。古いデータにも true が入る
- おやすみタイマーで眠っているあいだは、今まで通り描かない

## 確認URL

| 環境 | URL |
|------|-----|
| 本番 | https://kiyotake1229.github.io/nagi-pond/ |
| 自動テスト | `node tools/test.mjs` |

確認したこと: 自動テストで画面の書き換えを毎秒60回起こし、実際に描いた回数を数えた。触っているあいだ毎秒60回、30秒後に30回、5分後に20回、触ると60回に戻る。設定でオフなら60回のまま、呼吸中も60回。省電力の処理を外したコピーではテストが失敗する。Claude のブラウザは画面が裏に隠れていて書き換えが止まるため、実際の回数はそこでは測れなかった。
