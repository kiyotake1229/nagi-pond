# 引き渡し手順の「必要な環境」を Xcode 26・Node.js 20 に（凪の池）

- 管理番号: #0034
- 種類: DOC（ドキュメント作成）

- 作成日: 2026-11-06
- 関連: #0033（プライバシーマニフェスト・ビルド確認）

## 概要

岩崎さんへの引き渡し手順の「必要な環境」が古いままだった。このアプリは Capacitor 7 のため、Xcode 27 でビルドすると起動しないおそれがある。Xcode 26 を使うこと、macOS ごとに使う Xcode の版、入手先、Node.js 20 以降を書いた。

## 対象ファイル

- `ios-app/岩崎さんへの引き渡し手順.md`（2章「必要な環境」）

## 変更内容

- 2章「必要な環境」の前の書き方: 「Xcode 15 以降が動く macOS」「Xcode（版の指定なし）」「Node.js 18 以降」
- Xcode: **Xcode 26.x** を使い、**Xcode 27 は使わない**と書いた。理由: このアプリは Capacitor 7 のままで UIScene に対応していない。Apple は Xcode 27（iOS 27 の SDK）でビルドしたアプリは UIScene に対応していないと起動しないとしている。Mac App Store からは Xcode 27 が入るので、Xcode 26 の入手先（Apple Developer の More Downloads）と、Xcode 27 も入っている Mac での切り替え方（`xcode-select`・`open -a`）も書いた
- macOS ごとに使う Xcode の表: Apple の対応表で 2026-11-06 に確認。Xcode 26.4.1〜26.6 は macOS Tahoe 26.2 以降、26.3 までは Sequoia 15.6 以降で動く。macOS 27 で動く Xcode 26 は無いので、その場合は清武に連絡してもらう
- Node.js:「18 以降」→「20 以降」。Capacitor 7 の CLI（7.6.9）は Node.js 20 以上が必要で、18 では `npx cap sync` などが動かない（`package-lock.json` の engines で確認）
- そなえ帳・思考力の手順書と同じ書き方にそろえた
