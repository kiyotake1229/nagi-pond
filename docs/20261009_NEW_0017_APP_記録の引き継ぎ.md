# 記録の引き継ぎ（引き継ぎコード）

- 管理番号: #0017
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-09
- 関連: #0005、#0011

## 概要

記録は端末の中にしかないため、機種変更や、ブラウザ版で遊んでからアプリ版を入れたときに、池を移す方法が無かった。設定に「記録の引き継ぎ」を足し、池をまるごと1つの文字列（引き継ぎコード）にして、移したい先で貼り付けて戻せるようにした。通信はしない。

## 対象ファイル

- `index.html`（設定の「記録の引き継ぎ」、`exportCode` / `parseCode`）
- `support.html`（よくある質問・プライバシーポリシーに追記）
- `ios-app/岩崎さんへの引き渡し手順.md`（説明文・確認項目に追記）

## 変更内容

- コードの形: `NAGI1.` ＋ 保存データ（JSON を UTF-8 にして base64）。通知の設定（`notify` / `notifyHour`）は端末ごとの許可なので入れない
- 「コードを作る」→ コードを表示し、「コピーする」でクリップボードへ。コピーできない環境では、コードを選んだ状態にして案内を出す
- 「コードから戻す」→ 貼り付けて「戻す」。空白や改行が混ざっていてもよい。形が違う・途中で切れている・壊れているときは、その理由を出す。正しければ「鯉◯匹・満開◯回の池です」と出し、もう一度押すと今の池と置き換わる（`applyState`）。貼り付け欄を書き換えたら確認をやり直す
- 戻すデータも保存データと同じ検査（`sanitize`）を通す
