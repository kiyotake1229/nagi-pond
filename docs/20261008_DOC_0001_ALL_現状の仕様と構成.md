## 概要

凪の池（なぎのいけ）は、夜の池の水面に触れて波紋と音を楽しむ、スマホ向けのリラックスゲーム。波紋で蓮を咲かせ、五輪すべて咲く（満開）と新しい鯉がやってくる。鯉は水面に落ちた餌を食べて育つ。時間制限や失敗はない。2026-10-08 に新規作成した初版（1.0.0）の内容をまとめる。以後の変更は #0002 以降に記録する。

## 仕様

### 遊び方

| 操作 | 起きること |
|---|---|
| 水面をタップ | 波紋が広がり、タップした位置（左が低く右が高い）に合わせた音が鳴る。餌が1粒落ちる |
| 水面をなぞる | 小さな波紋が続けて広がり、音階を順に鳴らす（ハープのような音） |
| 何もしない | ときどき自然のしずくが落ちて波紋ができる。鯉は泳ぎ続ける |

- 波紋がつぼみに届くと、つぼみに「ひらく力」がたまる。近いほど多くたまる。`BLOOM_NEED`（=4）たまると蓮が咲く
- 池には毎回5つの葉とつぼみがある。五輪すべて咲くと「満開」になり、画面中央に縦書きで「満開」と出る
- 満開のあと約2秒で新しい鯉が画面の外から入ってくる。約11秒後に葉と花が消え、3秒後に新しい5つのつぼみが出る
- 波紋は葉・花びら・落ち葉・灯籠・餌を外へ押し流す

### 鯉

- 12種類。めずらしさは3段階（よく見る10 / ときどき5 / めずらしい2 の重み。まだ見ていない種類は2.5倍出やすい）

| 種類 | 内部名 | めずらしさ |
|---|---|---|
| 紅白 | kohaku | よく見る |
| 大正三色 | sanke | よく見る |
| 昭和三色 | showa | ときどき |
| 丹頂 | tancho | めずらしい |
| 白写り | shiro | よく見る |
| 緋写り | hiutsuri | ときどき |
| 浅黄 | asagi | ときどき |
| 秋翠 | shusui | めずらしい |
| 黄金 | ogon | ときどき |
| プラチナ | platinum | ときどき |
| 孔雀 | kujaku | めずらしい |
| 茶鯉 | chagoi | よく見る |

- 模様は1匹ずつ違う。種類と個体の「種」（`seed`）から毎回同じ模様を作る（`makeLook`）
- 池に住めるのは9匹まで（`POND_MAX`）。満開でいっぱいのときは「訪れた鯉」が45秒ほど泳いで帰る。図鑑には登録される
- 最初の起動時に3匹（紅白・大正三色・茶鯉）がいる
- 餌を食べると育つ。粒数で段階が変わり、体の大きさは少しずつ大きくなる

| 段階 | 必要な粒数 |
|---|---|
| 稚魚 | 0 |
| 若鯉 | 6 |
| 成鯉 | 20 |
| 大鯉 | 45 |

- 動きは「頭が向きを少しずつ変えながら進み、体の12個の節が後を追う」作り。節どうしの曲がりは0.3ラジアンまでに抑えて、自然にくねる
- 餌が近くにあると水面近くに浮いてきて食べに行く。ふだんは深さが変わり、深いときは水の色が重なって見える

### 池のしつらえ（満開の回数で増える）

| 満開の回数 | 追加されるもの |
|---|---|
| 2 | 白蓮（白い蓮が咲く） |
| 4 | 鹿威し（45〜85秒ごとに竹の音） |
| 6 | 黄蓮 |
| 9 | 青蓮 |
| 12 | 浮き灯籠（夕暮れと夜に3つ浮かぶ） |
| 16 | 紫蓮 |

### 景色と季節

- 景色は「おまかせ」で時刻に合わせて変わる（5〜8時 朝、9〜15時 昼、16〜18時 夕、それ以外 夜）。設定で固定もできる
- 季節は「おまかせ」で二十四節気に合わせる（立春〜穀雨 春、立夏〜大暑 夏、立秋〜霜降 秋、立冬〜大寒 冬）。設定で固定もできる

| 季節 | 演出 |
|---|---|
| 春 | 桜の花びらが降って水面に浮かぶ |
| 夏 | 蛍が飛ぶ（夕・夜）。虫の声 |
| 秋 | もみじが落ちて水面に浮かぶ。夕・夜は虫の声 |
| 冬 | 雪が降り、ときどき水面に小さな波紋 |

- 左上に、いまの二十四節気の名前と読みを縦書きで出す。タイトル画面には意味も出す（例: 寒露 冷たい露が降りるころ）。日付は年により1日ほど前後する

### 音

- すべて WebAudio で作る。音源ファイルは無い
- 環境音と音楽: 低くこもった水の音、15秒ずつ重なる和音、鹿威し、虫の声
- 効果音: 波紋の音（鐘のような音）、しずく、開花、満開、成長
- 音階は景色ごとに決まった五音音階（夜 D、朝 G、昼 C、夕 A）で、どこを触っても濁らない
- 残響（リバーブ）は、ノイズから作った響きを使う
- 最初のタップ（「水面に触れる」）で音の準備をする。アプリが裏に回ると音を止める

### 呼吸

- 画面中央の輪が広がるときに吸い、縮むときに吐く。吐くときに中央から波紋が出る
- 3種類: ととのう（5秒吸う・5秒吐く）、ねむる（4・7・8）、しずめる（4・4・4・4）
- 長さは1分・3分・5分。区切りの良いところ（1周の終わり）で終わる
- 20秒以上続けると「呼吸の回数」と時間を記録する。対応する端末では画面が消えないようにする（Wake Lock）

### 記録

- 今日池にいた時間、続けて来ている日数（1日1分以上）、これまでの合計時間、満開の回数
- この一週間の棒グラフ、咲かせた蓮の数、呼吸の回数、池の鯉の数
- 池のしつらえの解放状況と、次の解放まであと何回か

### 設定

- 環境音と音楽 / 効果音 / 音量 / 振動
- 景色（おまかせ・夜・朝・昼・夕）、季節（おまかせ・春・夏・秋・冬）
- 鹿威し・浮き灯籠のオンオフ（解放後）
- おやすみタイマー（なし・15分・30分・60分）。時間がくると音が静かに消え、画面が暗くなる。触ると戻る。タイマーは保存しない
- 記録をすべて消す（2回押しで実行。音の設定は残す）
- 右上のボタンで音をまとめて消せる

### 画面の部品

| 部品 | 内容 | HTML の id・関数 |
|---|---|---|
| タイトル | 縦書きの「凪の池」、二十四節気、「水面に触れる」 | `#title`、`start` |
| 池 | 全画面の canvas | `#pond`、`update` / `draw` |
| 上の帯 | 節気、蓮の開花数（5つの蓮の印）、音ボタン、おやすみタイマーの残り | `#sekki` `#buds` `#muteBtn` `#sleepChip` |
| 下のメニュー | 呼吸・図鑑・記録・設定 | `#dock`、`openSheet` |
| シート | 下から出る画面。中身は開くたびに作る | `#sheet`、`breathHTML` `zukanHTML` `recordHTML` `settingsHTML` |
| 案内 | 初回だけ3段階で操作を案内 | `#hint`、`showHint`、保存値 `hint` |
| 通知 | 鯉の到着・成長・しつらえの解放 | `#toasts`、`toast` |
| 呼吸 | 輪の中の「吸う」「とめる」「吐く」と秒数、残り時間 | `#breath`、`breathStart` |

- 7秒操作が無いと、上の帯と下のメニューを薄くする（池に集中できるように）

### 保存

- localStorage のキー `nagi.v1` に JSON で保存する。外部には送らない
- 主な中身: `koi`（池の鯉。id・種類・種・粒数・来た日時）、`seen`（図鑑）、`blooms`（咲かせた蓮）、`fulls`（満開の回数）、`days`（日ごとの秒数。70日より前は消す）、`breaths` / `breathSec`、`hint`、`set`（設定）
- 保存できない環境（プライベートブラウズなど）でも遊べる。その場合は閉じると消える

### 触覚

- タップで軽く、開花で軽く、成長で中くらい、満開で成功の振動
- Android のブラウザは `navigator.vibrate`。iOS アプリ化したときに Capacitor の Haptics が入っていれば、そちらを使う（`buzz`）。iPhone の Safari では振動しない

### 通信

- しない。外部のフォント・ライブラリも読み込まない（文字は端末の明朝体・ゴシック体）
- Service Worker は通常の Web 公開時だけ登録する（Claude Artifact と iOS アプリでは登録しない）

- 図鑑・記録・設定・呼吸の各画面が開き、ボタンが効く

- 再読み込みしても鯉・満開の回数・時間の記録が残る
- 60fps で動く
- Service Worker が登録され、manifest とアイコンが読める
- エラーは出ていない
