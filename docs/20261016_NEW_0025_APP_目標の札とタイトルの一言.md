# 目標の札とタイトルの一言（何をするゲームかを見えるように）

- 管理番号: #0025
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-16
- 関連: #0026（今日のお題）、#0027（めずらしい鯉）

## 概要

「何をするゲームか分かりにくい」という声を受け、遊ぶ目的を画面に出した。タイトル画面に「蓮を咲かせて、鯉を集める」と一言添え、遊んでいるあいだは上の蓮の印の下に「図鑑 4/12 ・ お題 1/3」の札を出す。札を押すと「目標」の画面が開く。

## 対象ファイル

- `index.html`（タイトル、上の帯、目標の画面 `goalsHTML`、札 `renderGoal`）

## 変更内容

- タイトル画面: 題の下に「蓮を咲かせて、鯉を集める」（明朝・ゆっくり表示）
- 上の帯の真ん中を2段にし、蓮の印の下に札（`#goalBtn`）。図鑑の種類数と今日のお題の達成数。3つ達成すると「お題 達成」（金色）。お題を達成するたびに札が少し弾む
- 目標の画面（シート `goals`）: 今日のお題3つ（進み具合の棒・達成の印）、ごほうびの説明、図鑑の進み（まだ見ぬ鯉をめずらしさ別に）、大鯉の数、次のしつらえまでの満開の回数、「図鑑を見る」ボタン
- 初めての満開のあと、9秒後に「上の札から、今日のお題と図鑑の進みが見られます」と案内する
- 知らせの位置を札の下に下げた（札が知らせで隠れないように）
- 操作が無く薄くなったときは、札のすりガラスのぼかしも外す（#0024 と同じ）
