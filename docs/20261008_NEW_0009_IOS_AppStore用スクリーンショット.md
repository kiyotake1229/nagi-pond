# App Store 用スクリーンショット

- 管理番号: #0009
- 種類: NEW（新機能）
- 対象: iOSアプリ（IOS）
- 作成日: 2026-10-08
- 関連: #0005、#0006

## 概要

App Store Connect に載せるスクリーンショットを、見出し入りで5場面×4サイズ作った。MAZE の撮影の仕組み（画面なしの Chrome で台紙を開いて撮る）を流用した。

## 対象ファイル

- `tools/make-screenshots.mjs`（新規。MAZE のものを元に、場面名・一時フォルダ名・音を消す指定を変えた）
- `tools/screenshot-frame.html`（新規。この アプリ用の台紙と場面の用意）
- `ios-app/screenshots/`（出力。iphone-6.9 / iphone-6.5 / iphone-5.5 / ipad-13 に各5枚）
- `index.html`（テスト用の窓口 `window.__nagi` に `breathStart` を追加）

## 変更内容

| 番号 | 場面 | 見出し |
|---|---|---|
| 1 | 夜の池（蓮が咲きかけ、波紋） | 触れると、波紋と音がひろがる |
| 2 | 満開と新しい鯉の知らせ | 五輪咲けば、満開 |
| 3 | 図鑑（名前を付けた鯉） | 12種の鯉と出会う図鑑 |
| 4 | 呼吸 | 輪に合わせて、ゆっくり呼吸 |
| 5 | 夕暮れと雪、浮き灯籠 | 時刻と季節で、池が変わる |

- 撮影用の池の状態（鯉7匹・図鑑9種・満開13回）を保存領域に入れてから読み込む。音は消す（保存値の `mute: true` と Chrome の `--mute-audio`）
- 鯉の粒数は段階の境目から離し、撮影中に「育ちました」の知らせが写らないようにした
- 満開の場面は、満開になったのを確かめてから約3秒待って撮る（文字と新しい鯉の知らせが両方写る）
- 撮影中は画面の部品を薄くする処理を止める（呼吸中のメニューを消す処理は残す）
- 鯉の動きは毎回ちがうため、撮るたびに少し違う絵になる

使い方: `node tools/make-screenshots.mjs`（要 Node.js 22 以降と Google Chrome）
