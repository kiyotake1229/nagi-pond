- 管理番号: #0005

- 作成日: 2026-10-08

## 概要

`index.html` をそのまま同梱する iOS アプリのプロジェクトを `ios-app/` に作った。構成はそなえ帳（`自己開発/そなえ帳/ios-app/`）と同じ Capacitor 7。手元に Xcode が無いため、GitHub Actions（macOS）でビルドが通ることを確かめる。岩崎さん向けの引き渡し手順も書いた。

## 対象ファイル

- `ios-app/package.json` … Capacitor 7 と使う部品（filesystem / haptics / local-notifications / preferences / share / status-bar）。`npm run sync`・`npm run icons` など
- `ios-app/capacitor.config.json` … appId `work.ltv.nagi`、表示名「凪の池」。`contentInset: never`（池を画面の端まで描く）、`scrollEnabled: false`（画面が引っぱられて動かないように）、背景色 `#08151c`、ステータスバーは白い文字
- `ios-app/sync-web.sh` … 親フォルダの `index.html` などを `www/` にコピー（`sw.js` は入れない）
- `ios-app/ios/` … `npx cap add ios` で作った Xcode プロジェクト
- `ios-app/ios/App/App/Info.plist` … 開発言語を日本語、iPhone は縦画面のみ、ステータスバーを白い文字、写真への追加の説明文（`NSPhotoLibraryAddUsageDescription`）、暗号の申告（`ITSAppUsesNonExemptEncryption = NO`）
- `ios-app/ios/App/App.xcodeproj/project.pbxproj` … バージョン 1.1.0
- `ios-app/assets/` … アイコン（1024）と起動画面（2732）の元画像。`tools/make-icons.sh` で作る
- `ios-app/ios/App/App/Assets.xcassets/` … `npm run icons` で作ったアイコンと起動画面（使われていない既定の起動画面3枚は消した）
- `ios-app/.gitignore`、`.gitignore`
- `.github/workflows/ios-build.yml` … push のたびに GitHub の macOS で `npm ci` → `npm run sync-web` → `npx cap sync ios` → 署名なしで `xcodebuild build`
- `ios-app/岩崎さんへの引き渡し手順.md` … ビルドから申請までの手順と申請情報の下書き
- `index.html` … ネイティブとの橋渡し（`NATIVE` / `CAP`）、保存の二重化（`save` / `restoreNative`）、ステータスバー、版数 `VERSION = '1.1.0'`

## 変更内容

- 保存の二重化: localStorage に加えて、アプリ版は `Preferences` にも書く（0.4秒まとめて）。起動時に localStorage が空で `Preferences` に値があれば戻して読み込みなおす
- 触覚: `Haptics` があればそれを使う（タップは軽く、成長は中くらい、満開は成功）
- Service Worker はアプリ版では登録しない
- 手元での `npx cap add ios` は、最後の `pod install` が Xcode が無いことと日本語のフォルダ名で失敗する。プロジェクト自体はできているので、`pod install` は Xcode のある環境（と GitHub Actions）で行う
