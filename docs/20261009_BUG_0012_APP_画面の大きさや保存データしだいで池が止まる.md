# 画面の大きさや保存データしだいで池が止まる

- 管理番号: #0012
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-09
- 関連: #0001

## 概要

次のどちらかが起きると、例外で描画の繰り返しが止まり、池が動かなくなっていた（再読み込みするまで戻らない）。

1. 画面の大きさが一瞬 0 になる（アプリの起動直後、別の画面の裏で読み込まれたときなど）。大きさ 0 の下絵（四隅の暗がり・朝霧）を描こうとして例外になる
2. 保存データに知らない値が入っている（古い版のデータ・手で書き換えたデータ）。例えば景色が知らない名前だと、起動の時点で例外になる

## 対象ファイル

- `index.html`（`resize` / `frame` / `sanitize` / `load`）

## 変更内容

- `resize`: 画面と下絵の大きさを最低 1 にする
- `frame`: 次のコマを先に予約してから、更新と描画を `try` で囲む。例外が出ても池は動き続ける（例外は最初の3回だけ console に出す）
- `sanitize`（新規）: 保存データを読み込むときに検査して直す。設定（景色・季節・呼吸・長さ・音量・通知の時刻）は知っている値だけ、鯉は知っている種類だけを残し、粒数・種・来た日時を数に、重なった番号を振り直し、名前を10文字に、日ごとの記録は日付の形で正の数だけを残す。池の鯉は9匹まで
- 写真を作るのに失敗しても、知らせを出して止まらないようにした
