# 鯉に名前を付ける

- 管理番号: #0002
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-08
- 関連: #0001

## 概要

池の鯉に、利用者が名前を付けられるようにした。愛着を持って続けてもらうための機能。図鑑の「いまの池」で鉛筆のボタンを押すと、その場で名前を入力できる。

## 対象ファイル

- `index.html`

## 変更内容

- 鯉のデータに `name`（10文字まで）を追加。保存キー `nagi.v1` の `koi[].name`。空にして決めると名前を外す
- 図鑑「いまの池」の各行に鉛筆のボタン（`data-rename`）。押すとその行が入力欄（`form[data-rename-form]`）に変わり、入力欄に自動で合わせる。「決める」かキーボードの完了で保存（`submit` で処理）
- 名前がある鯉は「名前＋種類（小さく）」で表示。成長の知らせ（「〇〇が成鯉に育ちました」）にも名前を使う（`koiLabel`）
- 名前の無い鯉が育ったときは「図鑑で名前を付けられます」と案内する
- 入力中の行は `renaming`（鯉の id）で覚え、シートを閉じると戻す
- iOS の Safari では親要素の `user-select:none` で入力できなくなることがあるため、`input` に `user-select:text` を指定
