# 連続のごほうびの景色（雨の池・雪見灯籠）

- 管理番号: #0031
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-18
- 関連: #0029（お題の連続記録と景色「満月」）

## 概要

お題を続けて達成したごほうびの景色を、満月（7日）に加えて、雨の池（14日）・雪見灯籠（30日）の3つにした。長く続けるほど楽しみが増える。おまかせの景色でも、合う日にときどき現れる。

## 対象ファイル

- `index.html`（`STREAK_SCENES` / `sceneOpen` / `autoScene`、景色 `rain` / `yukimi`、`drawYukimi`、雨と雪の粒、雨の音、目標・設定の画面）
- `tools/test.mjs`（テスト3件）
- `tools/screenshot-frame.html` / `tools/make-screenshots.mjs`（雨の池・雪見灯籠の場面。撮る場面と端末を `NAGI_SCENES` / `NAGI_DEVICES` で絞れるようにした）
- `support.html`（よくある質問）

## 変更内容

- ごほうびの景色を一覧（`STREAK_SCENES`）にし、いちばん長い連続日数で解放する。解放したらその場で景色を変え、知らせを出す。次のごほうびまでの日数を「お題 ◯日連続／景色『◯◯』まで、あと◯日」で知らせる
- 景色「雨の池」: 灰青の水面に雨粒の小さな輪（1秒に16個ほど。蓮や鯉には触れない別の輪）、斜めに降る雨の筋、うすい霧。雨の音（高い音を通したノイズ）と、ときどき雫の音
- 景色「雪見灯籠」: 夜の水面のほとり（左下）に、雪の積もった六角の笠の石灯籠を上から見た形で描き、温かい灯りを水面ににじませる。季節にかかわらず雪が舞い、水面に落ちると小さな輪
- おまかせの景色: 満月のころの夜は満月、梅雨のころ（6/11〜7/19）の日中は2日に1日ほど雨の池、冬（立冬〜大寒）の夜は3日に1日ほど雪見灯籠（どの日かは日付で決まる）。解放していなければ出ない
- 設定の景色を「いつもの景色」（おまかせ・夜・朝・昼・夕）と「特別な景色」（解放したものだけ）の2段にした
- 目標の画面の「お題の連続」に、ごほうびの一覧（7日 満月／14日 雨の池／30日 雪見灯籠。選べるか、あと何日か）を出す
- App Store 用スクリーンショットの5枚目の見出しを「続けるほど、特別な景色／7日で満月、14日で雨の池、30日で雪見灯籠」にした
