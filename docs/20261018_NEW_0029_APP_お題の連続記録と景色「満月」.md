# お題の連続記録と景色「満月」

- 管理番号: #0029
- 種類: NEW（新機能）

- 作成日: 2026-10-18
- 関連: #0026（今日のお題）

## 概要

今日のお題を3つすべて達成した日が何日続いているかを数え、7日続いたら特別な景色「満月」を選べるようにした。毎日続けて開く目標を作るため。解放したあとは、本物の満月のころの夜だけ、景色が「おまかせ」でも自動で満月の池になる。

## 対象ファイル

- `index.html`（`mstreak` / `streakNow` / `prevDay`、景色 `moon`、`moonAge` / `isFullMoon` / `autoScene`、星と水面の満月の描画、目標・設定・記録の画面）
- `tools/test.mjs`（テスト3件）
- `tools/screenshot-frame.html` / `tools/make-screenshots.mjs`（「満月の池」の場面を追加。8場面）
- `support.html`（よくある質問）

## 変更内容

- 保存データに `mstreak`（いまの連続日数 `count`・最後に達成した日 `last`・いちばん長い日数 `best`）を追加
- 3つそろった日: 前の日も達成していれば1日増やし、空いていたら1日目から。同じ日に何度そろえても1回だけ数える。2日目からは「お題 ◯日連続／景色『満月』まで、あと◯日」と知らせる
- 「いま」の連続日数は、最後に達成したのが今日か昨日ならその日数、それより前なら0日
- いちばん長い日数が7日に届いたら「満月」を解放する。その場で景色を満月に変え、「景色『満月』が選べるようになりました」と知らせる。いちど解放したら、連続が途切れても選べる
- 景色「満月」: 深い藍色の水面に、大きな満月（ゆらぐ光の円と光のにじみ）と、またたく星（70個）が映る。音は F の明るい五音音階
- 月齢は、2000年1月6日の新月から平均の満ち欠けの長さ（29.53日）で計算する。実際の満月（2024/10/17・2025/10/7・2026/1/3）との差は半日ほど。月齢13.5〜16日を「満月のころ」とし、その夜（19時〜5時）は「おまかせ」でも満月の池になる
- 目標の画面に「お題の連続」（いまの日数・いちばん長い日数・満月までの進み）、記録の画面に連続日数、設定の景色に「満月」（解放後）
