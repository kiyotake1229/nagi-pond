# 夜のお知らせ（iOS アプリ版のローカル通知）

- 管理番号: #0004
- 種類: NEW（新機能）
- 対象: iOSアプリ（IOS）
- 作成日: 2026-10-08
- 関連: #0005

## 概要

iOS アプリ版で、毎晩決まった時刻に「池からのお知らせ」を届けられるようにした。文面はその日の二十四節気に合わせて変わる（例:「寒露のころ。池にもみじが浮かんでいます」）。続けて使ってもらうためと、審査ガイドライン 4.2 の「ネイティブ機能」を満たすための機能。端末の中で予約する通知で、通信はしない。

## 対象ファイル

- `index.html`（設定画面と予約の処理。ブラウザ版では表示しない）
- `ios-app/package.json`（`@capacitor/local-notifications`）

## 変更内容

- 設定に「夜のお知らせ」を追加（`NATIVE && CAP.LocalNotifications` のときだけ表示）。ON/OFF と時刻（20・21・22・23時）
- ON にしたときだけ通知の許可を求める（`toggleNotify`）。許可されなければ OFF に戻し、iPhone の設定から許可する方法を知らせる
- `scheduleNotify`: id 7000〜7013 の予約を消してから、先の14日分を1日1件ずつ予約しなおす。文面は `NOTIFY_LINES`（季節ごとに2つ）から日付で選ぶ。アプリを開くたびに予約しなおすので、使っている限り途切れない
- 保存キーに `set.notify`（既定 false）、`set.notifyHour`（既定 21）を追加。「記録をすべて消す」でもこの設定は残す
