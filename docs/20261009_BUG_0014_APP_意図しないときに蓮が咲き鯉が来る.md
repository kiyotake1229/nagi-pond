# 意図しないときに蓮が咲き、鯉が来る

- 管理番号: #0014
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-09
- 関連: #0001

## 概要

次の3つの場面で、利用者が触っていないのに蓮が咲いたり鯉が来たりしていた。

1. タイトル画面のまま置いておくと、自然のしずくで蓮が咲き、満開になって鯉が増えることがあった
2. 呼吸の最中に、吐く息の波紋や自然のしずくで蓮が咲き、「満開」の文字や知らせが呼吸の輪に重なった
3. 満開の直後に「記録をすべて消す」と、消す前の満開で予約されていた鯉が、新しい池に入ってきた

## 対象ファイル

- `index.html`（`update` の自然のしずく、`phaseCue`、`celebrate`、`applyState`）

## 変更内容

- 自然のしずくは、遊び始めてから、かつ呼吸の最中でないときだけ蓮を開く力を持つ（波紋は今まで通り広がる）
- 呼吸の吐く息の波紋は、蓮を開く力を持たない
- 池をまるごと入れ替えるたびに番号（`gen`）を増やし、満開のあとに遅れて動く処理（鯉の到着・しつらえの知らせ）は、番号が変わっていたら何もしない
- 池の入れ替えを `applyState` にまとめた（はじめから・控えから戻す・引き継ぎで共通）

確認したこと: 自動テスト「遊び始める前（タイトル画面）は、放っておいても蓮が咲かない」（5分置いても、つぼみに力がたまらない）「呼吸の最中は蓮が咲かず、終わると回数が記録される」「はじめからやり直した後は、やり直す前の満開で予約された鯉が来ない」。修正前に戻すとテストが失敗することも確かめた。
