# マナーモードでも鳴らす（iPhone・iPad）

- 管理番号: #0019
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-10
- 関連: #0001、#0005

## 概要

iPhone は本体の消音スイッチ（マナーモード）が入っていると、このアプリの音（Web Audio）が鳴らない。日本ではマナーモードのまま使う人が多く、「音が出ない」と思われやすい。設定に「マナーモードでも鳴らす」を足し、オンにすると消音中も音が出るようにした。人前で急に鳴らないよう、初期はオフ。iPhone・iPad（iOS アプリ版を含む）でだけ設定に出す。

## 対象ファイル

- `index.html`（`IS_IOS` / `applySilentMode` / `silentWav`、設定、タイトルの案内）
- `support.html`（よくある質問「音が出ません」）
- `ios-app/岩崎さんへの引き渡し手順.md`（確認項目・審査で見られやすい点・説明文）

## 変更内容

- 保存データの設定に `ignoreMute`（初期 false）を追加
- `applySilentMode`: Audio Session API（iOS 16.4 以降の Safari / WebKit）があれば、オンで `navigator.audioSession.type = 'playback'`、オフで `'auto'`。無い古い端末では、0.5秒の無音の WAV（その場で作る data URI）を繰り返し流して、同じ扱いにする。画面が見えなくなったら無音の音声も止める
- 音を始めるとき（`audioStart`、最初のタップなど）に毎回当てる。設定を切り替えたら、音をいったん止めて鳴らし直して確実に反映し、知らせを出す
- `IS_IOS`: iPhone / iPad / iPod と名乗る端末、または「Mac と名乗るがタッチがある」端末（iPad）。ただし Android と名乗るものは除く（開発用のブラウザで Android を真似すると、Mac の上でタッチありになるため）
- タイトル画面の案内を、iPhone では「マナーモード中は、設定の『マナーモードでも鳴らす』で鳴らせます」に変えた

確認したこと: 自動テスト「iPhone では設定に出て、オンにすると Audio Session が『再生』になる」「iPad は iPhone の仲間、Android は違うと見なす」「PC や Android では設定に出ず、音の扱いも変えない」「Audio Session の無い古い iPhone では、無音の音声を流し、見えなくなると止める」。iPhone 実機で消音スイッチを入れて鳴ることは、手元に端末が無いため未確認。ほかのアプリの音楽と一緒に鳴るか止まるかも、実機で確かめる（引き渡し手順の確認項目に入れた）。
