# サポートページとプライバシーポリシー

- 管理番号: #0007

## 概要

App Store 申請に必要なサポートURL・プライバシーポリシーURLとして使うページ `support.html` を作った。MAZE の `support.html` と同じ構成（アプリについて・遊び方・よくある質問・プライバシーポリシー・お問い合わせ）で、見た目はアプリに合わせた。アプリの設定画面のいちばん下からもリンクしている。

## 対象ファイル

- `support.html`（新規）
- `index.html`（設定のいちばん下にリンク。`SUPPORT_URL`）

## 変更内容

- プライバシーポリシーの要点: 個人情報を収集しない／保存は端末内のみ（付けた名前も含む）／通信しない（共有を押したときだけ端末の共有機能に画像を渡す）／夜のお知らせはローカル通知／写真への保存は利用者が選んだときだけ
- よくある質問: 音が出ない、記録が消えた、振動しない、夜のお知らせを止めたい、寝る前に使いたい、やり直したい
- お問い合わせ: ltv.work / ai@ltv.work（他のアプリと同じ）
- 制定日 2026年10月8日
