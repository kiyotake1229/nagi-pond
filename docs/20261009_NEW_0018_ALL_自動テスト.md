## 概要

`index.html` のスクリプトをそのまま Node で動かし、24件の決まりごとを自動で確かめるテストを作った。MAZE の `tools/test.mjs` と同じ考え方で、画面・音・iOS の部品は最小限の偽物に置き換える。変更のたびに `node tools/test.mjs` で確かめる。

## 対象ファイル

- `tools/test.mjs`（新規）
- `.github/workflows/test.yml`（新規。`index.html` やテストを変えて GitHub に push するたびに、自動でテストを流す）
- `index.html`（テスト用の窓口 `window.__nagi` を広げた。1コマ進める `step`、保存データの検査 `sanitize` など）

## 変更内容

テストの内容:

| 分類 | 確かめること |
|---|---|
| 起動 | はじめての起動で鯉3匹・つぼみ5つ・保存・描画の予約 |
| 長く遊ぶ | 10分、触る・満開を繰り返しても例外が出ず、波紋・餌・光・浮かぶものが増え続けない。鯉の位置と大きさが数のまま |
| 満開 | 新しい鯉・図鑑・次のつぼみ。池がいっぱいなら訪れた鯉が来て帰る |
| 意図しない開花 | タイトル画面・呼吸中は咲かない。やり直し後に予約の鯉が来ない |
| 保存データ | 壊れたデータ5種類でも起動して遊べる。合計時間が70日で減らない。続けた日数 |
| 名前・引き継ぎ | 絵文字を途中で切らない。名前が HTML として動かない。コードの往復と、壊れたコードを断ること |
| iOS | 控えから戻る・控えを上書きしない。夜のお知らせ14日分の予約 |
| 暦・画面 | 二十四節気の境目、大きさ0、描画の例外、おやすみタイマー、写真 |

- 音の偽物は、本物と同じく `exponentialRampToValueAtTime` に 0 以下を渡すと例外にする。canvas の偽物は、大きさ0の canvas を描くと例外にする
- 時計は偽物で、予約された処理（鯉の到着など）も時間どおりに動かす
- 直した不具合をわざと元に戻したコピーで、それぞれのテストが失敗することを確かめた（`NAGI_HTML=コピー.html node tools/test.mjs`）

使い方: `node tools/test.mjs`（要 Node.js 18 以降。約5秒）
