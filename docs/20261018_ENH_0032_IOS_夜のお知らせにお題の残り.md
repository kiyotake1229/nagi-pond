# 夜のお知らせにお題の残り（iOS アプリ版）

- 管理番号: #0032
- 種類: ENH（機能改善）
- 対象: iOSアプリ（IOS）
- 作成日: 2026-10-18
- 関連: #0004（夜のお知らせ）、#0026（今日のお題）、#0029（お題の連続）

## 概要

夜のお知らせに、その日のお題の残りと連続日数を入れた。連続が途切れにくくなるように。

## 対象ファイル

- `index.html`（`notifyBody` / `notifySoon` / `scheduleNotify`）
- `tools/test.mjs`（テスト1件。既存の通知のテストを、どの時刻に流しても確かめられるように直した）

## 変更内容

- その日の通知の文面
  - お題が残っているとき: 「今日のお題 あと1つ。連続5日目がかかっています」（昨日まで続いていれば）、続いていなければ「今日のお題 あと2つ。池にもみじが浮かんでいます」のように季節のひとこと
  - 3つ達成した日: 「寒露のころ。今日のお題はすべて達成しました。池でひと息つきませんか」
- 明日以降の通知: 「寒露のころ。池にもみじが浮かんでいます。今日のお題が届いています」
- お題が進むたびに2秒まとめて予約しなおす。アプリを閉じる（見えなくなる）ときと、日付が変わってお題が新しくなったときも予約しなおす。通知が届く時刻の文面が、そのときの進み具合になる

## 確認URL

| 環境 | URL |
|------|-----|
| iOS | Xcode で実機またはシミュレータ（`ios-app/岩崎さんへの引き渡し手順.md` 3章） |
| 自動テスト | `node tools/test.mjs` |

確認したこと: 自動テスト「iOS: 今日のお知らせに、お題の残りと連続日数が入り、お題が進むと書き直される」（文面・予約しなおしの回数・14件のまま）。予約しなおしを外したコピーではテストが失敗する。実機で通知が届くことは、Xcode が無いため未確認（引き渡し手順の確認項目に入れた）。
