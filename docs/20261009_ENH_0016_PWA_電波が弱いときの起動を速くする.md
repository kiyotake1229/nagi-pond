# 電波が弱いときの起動を速くする

- 管理番号: #0016
- 種類: ENH（機能改善）
- 対象: PWA（PWA）
- 作成日: 2026-10-09
- 関連: #0001

## 概要

ホーム画面から開いたとき、Service Worker は本体（index.html）を先に通信で取りに行き、失敗したときだけ保存分を使っていた。電波が弱い場所（地下・寝室の奥など）では、通信が失敗するまで長く待たされ、画面が出なかった。

## 対象ファイル

- `sw.js`

## 変更内容

- 本体は、通信と「3秒待ってから保存分」の早い方を使う。保存分が無い（初めて開く）ときは通信を待つ。通信が失敗したら保存分
- 通信で取れたときだけ保存分を新しくする（エラーの返事は保存しない）
- 保存の名前を `nagi-v2` に上げ、古い保存分を入れ替える
