# 記録の「これまで」の合計時間が70日で減る

- 管理番号: #0013
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-09
- 関連: #0001

## 概要

記録の「これまで」は、日ごとの記録を足して出していた。日ごとの記録は70日より前を消すため、使い続けると「これまで」が減っていた。

## 対象ファイル

- `index.html`（`tickTime` / `recordHTML` / `sanitize`）

## 変更内容

- 保存データに `totalSec`（これまでの合計秒数）を足し、池にいるあいだ日ごとの記録と一緒に増やす。「これまで」はこれを表示する
- 古い版のデータには `totalSec` が無いため、読み込むときに、消す前の日ごとの記録の合計から始める

## 確認URL

| 環境 | URL |
|------|-----|
| ローカル | http://localhost:8791/ |
| 本番 | https://kiyotake1229.github.io/nagi-pond/ |
| 自動テスト | `node tools/test.mjs` |

確認したこと: 自動テスト「これまでの合計時間は、70日より前の日の分も消えない」（100日前に1時間・今日10分 → 1時間10分と表示）。
