# 実機の代わりの検証（WebKit での動作・マナーモード、省電力の計測）

- 管理番号: #0022
- 種類: INQ（調査）
- 対象: 全体（ALL）
- 作成日: 2026-10-12
- 関連: #0019（マナーモードでも鳴らす）、#0020（省電力）、#0023、#0024

## 概要

iPhone 実機と Xcode が手元に無いため、次の2つを代わりの方法で確かめた。

1. iPhone の Safari と同じ描画エンジン（WebKit）で、iPhone・iPad として動かし、「マナーモードでも鳴らす」の切り替えと、実際のタップでの遊び方を確かめた
2. 画面なしの Chrome で、触らずに置いたときの描く回数と CPU の仕事量を測り、省電力の効き目を数字で確かめた

結果、マナーモードの切り替えは WebKit で狙いどおりに動いた。省電力は「描く回数は狙いどおり減るが、CPU の仕事量は半分まで減らない」ことが分かり、改善した（#0024）。写真の画面で知らせがかぶる問題も見つけて直した（#0023）。

- `tools/webkit-check.mjs`（新規。WebKit での確認。要 Playwright。使い方はファイルの先頭）
- `tools/measure-power.mjs`（新規。省電力の計測）

## 1. WebKit での確認

Playwright（ブラウザを自動で動かす道具）の WebKit で、iPhone 15・iPad Pro 11 の大きさ・名乗り・タッチを再現し、音を消して実際にタップした。

| 確かめたこと | iPhone | 古い iPhone（Audio Session API を無くした状態） | iPad |
|---|---|---|---|
| iPhone・iPad と見なす | ○ | ○ | ○ |
| 「マナーモードでも鳴らす」をタップでオン | 音の扱いが `playback`（再生） | 無音の音声（0.5秒）が読み込まれ、繰り返し流れる | `playback` |
| もう一度タップでオフ | `auto` に戻る | 無音の音声が止まる | `auto` に戻る |
| タップで蓮を咲かせて満開・新しい鯉 | ○ | ○ | ○ |
| 池の写真（1080×1350）・図鑑 | ○ | ○ | ○ |
| 縦書きの題・すりガラス・シートの見た目 | 崩れなし | 崩れなし | 崩れなし |
| エラー | 0件 | 0件 | 0件 |

分かったこと:

- WebKit には Audio Session API があり、`navigator.audioSession.type` を `playback` にすると読み返しても `playback` になる（書いた値が受け付けられる）
- 写真の確認画面を開いた直後、前の知らせ（新しい鯉など）が写真の上にかぶっていた → #0023 で直した

確かめられなかったこと: 実機の消音スイッチを入れたときに実際に音が出るか、ほかのアプリの音楽が止まるか。これは iPhone 実機でしか分からない（引き渡し手順の確認項目に残した）。

## 2. 省電力の計測

画面なしの Chrome で、スマホの大きさ（390×844）で開き、「省電力オフ」「オン・触らず30秒たった状態」「オン・触らず5分たった状態」を20秒ずつ、順番を回して3回測り、中央値を取った。CPU の仕事量は Chrome のすべてのプロセス（画面の描画・GPU の代わりの処理を含む）の合計。

注意: 画面なしの Chrome は GPU を使わずに絵を描くため、画素を細かく（3倍）すると毎秒60回に届かず、比べられなかった（最初の計測で、省電力オフでも毎秒30回だった）。そのため画素の細かさ1倍で測った。電池の減りそのものではないが、CPU の仕事量は電池の減りとほぼ比例する。

| 触らずに置いたとき | 描く回数 | v1.3.0 の CPU | v1.3.1 の CPU（#0024 の後） |
|---|---|---|---|
| 省電力オフ | 毎秒60回 | 322 ms/秒 | 274 ms/秒 |
| 省電力オン・30秒後 | 毎秒30回 | 231 ms/秒（28%減） | 180 ms/秒（**入れる前より44%減**） |
| 省電力オン・5分後 | 毎秒20回 | 180 ms/秒（44%減） | 133 ms/秒（**入れる前より59%減**） |

分かったこと（#0024 で直した）:

- 描く回数を半分にしても、仕事量は半分まで減らなかった。描くかどうかに関係なく、画面の書き換えのたびにアプリが呼ばれていたこと、上の帯と下のメニューのすりガラスのぼかしを描き直していたことが残っていた
- 試しにぼかしを全部外すと、仕事量はさらに13〜19%減った

使い方: `node tools/measure-power.mjs`（約4分。音は消して動かす）
