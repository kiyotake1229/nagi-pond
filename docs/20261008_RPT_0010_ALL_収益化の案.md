# 収益化の案

- 管理番号: #0010
- 種類: RPT（報告書）
- 対象: 全体（ALL）
- 作成日: 2026-10-08
- 関連: #0005

## 概要

凪の池で収益を得る方法を比べ、進め方を提案する。結論は「最初の版は無料・課金なしで出して評価を集め、次の版で『応援（投げ銭）』と『景色の追加パック』を買い切りで足す」。広告と月額課金は勧めない。この文書は案で、実装はしていない。

## 対象ファイル

- なし（提案のみ。実装する場合は `index.html` と `ios-app/` を変える）

## 比べた方法

| 方法 | 内容 | 向き不向き |
|---|---|---|
| 応援（投げ銭） | 120円・370円・730円の「お礼」。中身は変わらない | ◎ 作りが簡単で、遊びを邪魔しない。収益は小さい |
| 買い切りの追加パック | 景色パック（雨の池・満月・雪見灯籠）、鯉パック（五色・九紋竜・松葉など6種）、音パック（風鈴・雨音・琴）を各160〜370円 | ◎ 図鑑と景色の仕組みにそのまま乗る。「集める」楽しさとつながる |
| 全部入りの解放 | 480円前後で、今後のパックもすべて | ○ 分かりやすい。パックが増えてから |
| 月額課金 | 毎月新しい景色など | △ 毎月作り続ける必要がある。審査でも内容の継続性を見られる |
| 広告 | バナー・動画広告 | × くつろぐ体験を壊す。広告の仕組みが利用者の情報を集めるため、「データを収集しません」と言えなくなり、プライバシーポリシーも変わる |

## 進め方の提案

1. **v1.1（今回）**: 無料・課金なしで申請する。審査を通しやすく、評価（★）とレビューを先に集める
2. **v1.2**: 「応援」と「景色パック1つ」を足す。売れ方を見る
3. **v1.3 以降**: 反応がよければ鯉パック・音パックを足し、全部入りを用意する

## 技術面の注意

- 課金は App Store の仕組み（StoreKit）を使う。Capacitor 用の課金の部品を足す。外部の集計サービス（RevenueCat など）は利用者の情報を扱うため、使うならプライバシーの申告が変わる。端末内だけで完結する作りを勧める
- 買ったものは端末内に記録し、「購入を復元」ボタンを必ず置く（審査で求められる）
- Web 版（GitHub Pages）では課金できないため、追加パックは iOS アプリ版だけの機能にする
- 社内で必要なもの: App Store Connect の「有料 App 契約」、税・口座の情報
