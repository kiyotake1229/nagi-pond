# 写真の画面で、知らせが写真にかぶる

- 管理番号: #0023
- 種類: FIX（軽微な修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-12
- 関連: #0003（池の写真）、#0015（知らせを一番手前に出した）、#0022（見つけた検証）

## 概要

#0015 で知らせ（トースト）を一番手前に出すようにしたため、池の写真の確認画面を開いた直後に「新しい鯉がやってきました」などの知らせが残っていると、写真の上の方に数秒かぶっていた。WebKit（iPhone と同じ描画エンジン）での確認（#0022）で見つけた。

## 対象ファイル

- `index.html`（CSS と `takePhoto` / `closePhoto`）
- `tools/test.mjs`（「池の写真が作れる」に確認を追加）

## 変更内容

- 写真の画面を開いているあいだは `body` に `photo-open` を付け、知らせを画面の下（共有ボタンの下の案内文のあたり）に出す。閉じると元の位置（上）に戻る
- 共有できなかったときの案内（「この画面からは共有できません」）も、共有ボタンの近くに出るようになった
