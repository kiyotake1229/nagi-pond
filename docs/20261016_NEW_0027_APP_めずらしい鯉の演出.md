# めずらしい鯉の演出

- 管理番号: #0027
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-16
- 関連: #0026（ごほうびでめずらしい鯉が来る）

## 概要

めずらしい鯉（丹頂・秋翠・孔雀）が来たとき、特別な出会いだと分かる演出を足した。はじめて出会う鯉にも控えめな光を付けた。

## 対象ファイル

- `index.html`（`rareShow`、`Koi` の `aura`、CSS `.rare`）

## 変更内容

- めずらしい鯉が池に入ってくると、約1秒後に画面の中央へ「めずらしい鯉」と名前（例: 秋翠）を大きく出す（5秒で消える）。画面がやわらかく光り、上がっていく和音ときらめく音、触覚
- 知らせを「めずらしい鯉がやってきました」（池がいっぱいなら「めずらしい鯉が池を訪れました」）にした
- 鯉が光をまとう: めずらしい鯉は金色で14秒、はじめて出会う鯉は白で6秒。体のまわりが光り、通ったあとに光の粒が残る
- 光をまとう鯉がいるあいだは、省電力でも毎秒60回で描く（なめらかに見せる）
