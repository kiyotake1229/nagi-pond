# 満開の文字が表示中にぼやけていく

- 管理番号: #0006
- 種類: BUG（バグ修正）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-08
- 関連: #0001、#0009（スクリーンショットを撮るときに見つけた）

## 概要

満開のときに画面中央に出る「満開」の文字が、はっきり見えるはずの間も少しずつぼやけていた。

## 対象ファイル

- `index.html`（CSS の `@keyframes bigin`）

## 変更内容

- 原因: アニメーションの 75% の時点で `filter` を指定していなかったため、22%（ぼかし無し）から 100%（ぼかし 6px）まで、ぼかしがずっと少しずつ強くなっていた
- 75% の時点にも `filter: blur(0)` と `transform: none` を書き、22%〜75% の間ははっきり見えるようにした

確認したこと: スクリーンショットの「満開」の場面（満開から約3秒後）で文字がはっきり写る。
