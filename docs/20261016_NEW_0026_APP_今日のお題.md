# 今日のお題

- 管理番号: #0026
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-16
- 関連: #0025、#0027

## 概要

毎日3つのお題を出す。3つすべて達成すると、ごほうびとして次の満開で必ずめずらしい鯉がやってくる。毎日開く理由を作り、「めずらしい鯉を集める」目的につなげる。

## 対象ファイル

- `index.html`（`MISSION_TYPES` / `makeDaily` / `ensureDaily` / `mission` / `sanitizeDaily`、`rollKind`）
- `tools/test.mjs`（テスト4件）
- `support.html`（遊び方に「今日のお題」）

## 変更内容

- お題の種類と量（量は候補から選ぶ）

| 種類 | 文面の例 | 量 |
|---|---|---|
| bloom | 蓮を8輪咲かせる | 6・8・10 |
| bloomColor | 白蓮を3輪咲かせる（解放した色だけ） | 3・4 |
| full | 満開を1回 | 1・2 |
| feed | 鯉に餌を15粒あげる | 10・15・20 |
| glide | 水面をなぞって、音を15回鳴らす | 15・25 |
| breath | 呼吸を1分以上する | 1 |
| photo | 池の写真を1枚撮る | 1 |
| stay | 池で5分すごす | 5分・8分 |

- その日のお題は日付から決める（同じ日なら何度開いても同じ）。種類は重ならず、「蓮を咲かせる」と「◯◯の蓮を咲かせる」は同じ日に出さない
- 日付が変わったら作り直す（起動時・20秒ごと・お題が進むたびに確かめる）
- お題を達成すると、知らせ・和音・触覚。3つそろうと「今日のお題をすべて達成／次の満開で、めずらしい鯉がやってきます」
- ごほうび（`rareBoost`）: 次の満開で、めずらしい鯉（丹頂・秋翠・孔雀。まだ出会っていない種類を優先）が必ず来る。使うまで翌日以降も残る
- 遊び始める前（タイトル画面）は進まない
- 保存データに `daily`（日付・3つのお題・進み・ごほうび済み）と `rareBoost` を追加。壊れていたら作り直す。引き継ぎコードにも入る
