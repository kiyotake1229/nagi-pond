# 岩崎さんへ — 「凪の池」iOSアプリ ビルド・申請手順

岩崎さん

波紋と鯉のリラックスゲーム「凪の池」のiOSプロジェクトです。
**Xcodeで開いてビルド → App Store申請** まで進められる状態になっています。

必要な作業は大きく2つです。

1. Xcodeで開いて、署名（Team）を自社アカウントに設定してビルド → 3章
2. App Store Connect にアップロードして審査に提出 → 4章

申請時に入力するアプリ名・説明文・キーワードなどは、4章に**下書きを用意してあります**。
App Store 用のスクリーンショットも、必要なサイズをすべて作ってあります（`screenshots/`）。
そのまま使っていただいても、修正いただいても構いません。

ご不明な点があればお知らせください。

## 1. アプリ概要

| 項目 | 内容 |
|------|------|
| アプリ名 | 凪の池 |
| Bundle ID | `work.ltv.nagi` （変更する場合は Xcode の Signing & Capabilities で変更できます） |
| 構成 | Capacitor 7（WebView同梱型ネイティブアプリ。通信してWebサイトを表示する作りではありません） |
| 対応 | iPhone（縦画面固定）/ iPad |
| 通信 | **なし**（完全オフライン動作。外部のフォントや画像も読み込みません） |
| データ | **端末内のみ**（localStorage＋ネイティブ保存の二重化）。外部送信・収集は一切なし |
| ネイティブ機能 | ローカル通知（夜のお知らせ）、触覚フィードバック、共有シート（池の写真）、画像の保存 |
| バージョン | 1.1.0（アプリ内の「設定」のいちばん下に表示） |

## 3. ビルド手順

このフォルダ（`ios-app/`）で、以下を順に実行してください。

```bash
# 1) 依存パッケージを取得
npm install

# 2) Web本体をコピーして、iOSプロジェクトに反映（pod install もここで走ります）
npm run sync

# 3) Xcodeで開く
open ios/App/App.xcworkspace
```

> **注意**: 必ず `App.xcworkspace` を開いてください（`App.xcodeproj` ではありません）。

> `pod install` はこちらの環境（Xcode無し）では実行できていません。上記 2) で自動的に実行されます。
> 日本語を含むフォルダ名でエラーになる場合は、先に `export LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8` を実行してください。
> 同じ手順で GitHub Actions（macOS）上のビルドが通ることは**確認済み**です（v1.1.0: 2026-10-08）。結果はリポジトリの Actions タブで見られます。
> https://github.com/kiyotake1229/nagi-pond/actions

### Xcode上での設定

1. 左ペインで **App** を選択 → **Signing & Capabilities** タブ
2. **Team** に自社のApple Developerアカウントを選択（"Automatically manage signing" はON）
3. 必要に応じて **Bundle Identifier** を自社のものに変更
4. **General** タブで **Version**（1.1.0 に設定済み）と **Build**（例: 1）を確認

### 動作確認

- 上部のデバイス選択から実機またはシミュレータを選び ▶ で起動
- 「水面に触れる」で始まります。**音が出ます**（本体の消音モードがONだと鳴りません）
- 実機でご確認いただきたい点：
  - 水面をタップすると波紋と音、軽い触覚があること
  - 蓮を5つ咲かせると「満開」になり、新しい鯉が入ってくること
  - 右上のカメラのボタン →「共有する」で共有シートが開き、「画像を保存」で写真に保存できること（初回は写真への追加の許可が出ます）
  - 「設定」→「夜のお知らせ」をONにすると通知の許可が出て、選んだ時刻に通知が届くこと
  - 画面上部の時計・電池の表示が、暗い背景の上で白く見えること

## 4. App Store申請

1. Xcode: **Product → Archive**
2. Organizerが開いたら **Distribute App → App Store Connect** でアップロード
3. [App Store Connect](https://appstoreconnect.apple.com) でアプリ情報を入力して審査提出

### 申請情報（下書き）

**アプリ名**
```
凪の池 - 波紋と鯉のリラックスゲーム
```

**サブタイトル（30字以内）**
```
触れて、咲かせて、ひと息つく
```

**説明文**
```
「凪の池」は、夜の池の水面に触れて、波紋と音を楽しむリラックスゲームです。
時間制限も、失敗もありません。疲れた日の終わりや、寝る前のひとときに。

■ 触れると、波紋と音がひろがる
水面をタップすると波紋が広がり、やわらかな音が鳴ります。どこを触っても濁らない音階なので、気ままに触れるだけで小さな音楽になります。なぞると、音が順に流れます。

■ 蓮を咲かせ、鯉を迎える
波紋がつぼみに届くと、蓮が少しずつ開きます。五輪すべて咲くと「満開」。新しい鯉が池にやってきます。

■ 12種類の鯉と図鑑
紅白、大正三色、昭和三色、丹頂、黄金、秋翠、孔雀など12種類。模様は一匹ずつ違います。水面に落ちた餌を食べて、稚魚から大鯉まで育ちます。お気に入りの鯉には名前を付けられます。

■ 時刻と季節で、池が変わる
時刻に合わせて、夜・朝霧・昼・夕暮れへ。二十四節気に合わせて、桜の花びら、蛍、紅葉と虫の声、雪が池を彩ります。

■ 池のしつらえ
満開を重ねると、白蓮、鹿威しの音、浮き灯籠などが加わります。

■ 呼吸
池に浮かぶ輪に合わせて、ゆっくり息をします。「ととのう」「ねむる」「しずめる」の3種類、1・3・5分から選べます。

■ 寝る前に
おやすみタイマーで、音が静かに消えて画面が暗くなります。

■ その他
・池の今を一枚の写真にして共有
・今日の時間と、続けた日数の記録
・夜のお知らせ（季節のひとこと付き）
・完全オフライン動作。データは端末内にのみ保存され、外部に送信されません。広告・課金はありません。
```

## 5. 審査で見られやすい点

Appleガイドライン **4.2（最低限の機能）** について、本アプリは以下を満たしています。申請時の備考欄に記載すると安全です。

- 完全オフラインで動作する自立したアプリ（Webサイトの単なる表示ではない）。絵はその場で描き、音もその場で作っています
- 端末内にデータを保存し、継続的に利用する設計（鯉が育つ、図鑑、満開の回数でしつらえが増える、日々の記録）
- ネイティブのローカル通知・触覚フィードバック・共有シート（画像ファイル）を実装

**写真への保存について**：池の写真は、利用者が共有シートで「画像を保存」を選んだときだけ写真に追加されます（`NSPhotoLibraryAddUsageDescription` 設定済み。写真の読み取りはしません）。

**通知について**：通知の許可は、利用者が「設定」で夜のお知らせをONにしたときだけ求めます。起動時には求めません。

**健康に関する内容について**：呼吸の機能は、一般的なリラックスのための呼吸の目安を示すものです。医療・治療をうたう表現は使っていません。

**審査用メモ（備考欄の例）**
```
Nagi no Ike is a fully offline, relaxing game. Tap the night pond to make ripples and gentle pentatonic tones; ripples open lotus buds, and when all five bloom a new koi joins the pond. Koi grow by eating food dropped where you tap, can be named, and are recorded in a 12-variety collection. The pond changes with the time of day and the 24 traditional solar terms (cherry petals, fireflies, autumn leaves, snow). It also includes a guided breathing mode, daily records, a sleep timer, and a "pond photo" card shared via the share sheet. All graphics are drawn and all sounds are synthesized on device; no network requests are made and all data stays on the device. Native features: local notifications (optional nightly reminder, opt-in from Settings), haptics, and the share sheet (image files).
```

## 6. アプリ内容を修正したい場合

アプリ本体は 1つ上のフォルダの `index.html` です。修正後、このフォルダで：

```bash
npm run sync
```

を実行するとiOSプロジェクトに反映されます。その後Xcodeで再ビルドしてください。
Web版（サポートURL）は `index.html` を GitHub に push すると数分で更新されます。
アイコンを変えたいときは、1つ上のフォルダで `bash tools/make-icons.sh` → このフォルダで `npm run icons` です。
